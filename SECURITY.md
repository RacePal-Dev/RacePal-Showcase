# Security policy

This is a **documentation-only showcase**. For suspected vulnerabilities in the product or accidental disclosure, please contact the repository owner privately through GitHub instead of publishing details in a public issue.

Do not submit private telemetry, GPS data, credentials, private URLs, logs, internal reports, or exploit artifacts in issues or pull requests. Use synthetic, minimized examples. The public-content checker is a basic defense-in-depth tool, **not** a substitute for manual review or a full secret/history scan.
