# Contributions

RacePal is proprietary. This repository is a public engineering showcase, not an open-source distribution of the application.

Documentation corrections and reviews of the independently authored `examples/` sample are welcome. Do not submit private product source code, customer data, credentials, internal service URLs, or reconstructed proprietary algorithms.

Changes should have a focused Pull Request, proof of relevant tests, and a note about public-disclosure considerations. For security reports, use the private reporting guidance in [SECURITY.md](SECURITY.md).
