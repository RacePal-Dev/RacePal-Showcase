# Contributions

RacePal is proprietary. This repository provides architecture and engineering documentation, not an open-source distribution of the application.

Documentation corrections, accessibility improvements, and broken-link reports are welcome when they do not include private source material or sensitive data. Pull requests that reconstruct proprietary code, publish private operational details, or include customer information will not be accepted.

Security or intellectual-property concerns should be reported privately using [SECURITY.md](SECURITY.md). Changes to architectural claims, licensing, or the scope of public documentation require project-owner approval.
