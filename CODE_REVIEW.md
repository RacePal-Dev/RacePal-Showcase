# Public documentation review checklist

- Is every claim demonstrably true, and is its implementation state explicit?
- Could the text expose an unpublished algorithm, sensitive contract, deployment layout, account identifier, or exact private configuration?
- Are examples synthetic and labeled as such?
- Does a new document link only to material that exists in this public showcase?
- Are additions scoped to a clear purpose and easy to review?
- Do generated checks pass and has a human reviewed the diff?
- Does the change avoid suggesting the private source is public or this showcase is executable?
